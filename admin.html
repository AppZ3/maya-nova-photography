GitHub Setup

A GitHub Personal Access Token with repo scope is needed to upload images and publish changes. Create one at github.com → Settings → Developer settings → Personal access tokens. Your token is stored only in this browser.

Gallery Admin Key

Client galleries are managed through the site's own API, which needs an admin key. The gallery admin key is set in Vercel env ADMIN_KEY. Your key is stored only in this browser.

GitHub token

To create a token: go to github.com, open Settings, then Developer settings, then Personal access tokens, then Tokens (classic). Click Generate new token (classic), tick the repo scope, set expiration to 1 year or No expiration, then copy the token here. It is stored only in this browser and is used by the Portfolio tab.
